#  House Price Prediction Using Machine Learning

##  Project Description
This project is a Machine Learning based web application developed using Flask and Linear Regression to predict house prices based on property area and number of bedrooms. The application provides an interactive user interface along with graphical data visualization for better analysis of market trends.

---

##  Features
- Predicts house prices using Machine Learning
- Interactive web interface using Flask
- Linear Regression model implementation
- Graphical visualization using Chart.js
- Responsive and modern UI design
- Real-time prediction display

---

##  Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- HTML
- CSS
- Chart.js

---

##  Machine Learning Algorithm
- Linear Regression

The model is trained using sample housing data containing:
- Area
- Number of Bedrooms
- House Price

##  Installation and Execution

### Step 1: Install Python

Download and install Python.

### Step 2: Install Required Libraries

```bash
pip install -r requirements.txt
```

### Step 3: Run the Application

```bash
python app.py
```

### Step 4: Open Browser

Visit:

```text
http://127.0.0.1:5000
```
